RunSignup is an all-in-one race registration and event management platform serving running events, triathlons, cycling events, and obstacle courses. Their open REST API enables race directors, timing companies, affiliates, and technology partners to integrate race registration, participant management, results posting, fundraising, volunteer management, and event analytics into their own applications. The API supports OAuth 2.0 authentication and covers 100+ endpoints across 29 categories for comprehensive event lifecycle management.

**Areas:** Race Registration · Event Management · Running · Sports · Fitness · Timing · Fundraising

- [RunSignup Corrals API](https://apis.io/apis/runsignup/runsignup-corrals-api/) — Manage participant corrals for wave start events.

- [RunSignup Donations API](https://apis.io/apis/runsignup/runsignup-donations-api/) — Retrieve donation and fundraising data associated with race registrations.
- [RunSignup Participants API](https://apis.io/apis/runsignup/runsignup-participants-api/) — Manage race participants including registration, editing, deletion, bib/chip assignment, and participant data retrieval.
- [RunSignup Races API](https://apis.io/apis/runsignup/runsignup-races-api/) — List, search, and retrieve race and event information including details, events, schedules, and registration settings.
- [RunSignup Reference API](https://apis.io/apis/runsignup/runsignup-reference-api/) — Reference data such as countries and states used across the API.
- [RunSignup Results API](https://apis.io/apis/runsignup/runsignup-results-api/) — Submit, import, and retrieve race results including finishing times, result sets, and full results with place and time data.
- [RunSignup Teams API](https://apis.io/apis/runsignup/runsignup-teams-api/) — Manage teams and groups for team-based race events.
- [RunSignup Users API](https://apis.io/apis/runsignup/runsignup-users-api/) — Manage user accounts and authentication for the RunSignup platform.
